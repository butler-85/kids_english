farm-v1/ 存放农场用的本地 MP3，素材出处见 farm-v1/CREDITS.md。

本目录也可存放真人录制的字母音（自然拼读音素）mp3，作为浏览器语音的升级。

用法：
1. 放入录音文件，例如 a.mp3、b.mp3 ... z.mp3
2. 新建 manifest.json，格式：
   { "A": "a.mp3", "B": "b.mp3", "X": "x.mp3" }
   （只需登记实际放入的字母，未登记的自动使用浏览器语音）
3. 刷新页面即可生效（通过 http:// 访问时自动探测，直接双击 index.html 打开时不支持）

推荐录音来源（个人使用）：
- 自己对着每封信录制清晰的字母名 + 字音，例如 "B! /b/ ... Bear!"
- Wikimedia Commons 上有大量 CC 授权的字母发音录音可下载参考
